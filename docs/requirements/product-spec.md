# 产品规格

## REQ-001：Purity 节点地图

主网首页以整行地图替换 Ocean／Knots 两张卡片。仅统计 Seeder 哈希确认的 Purity 端点，IP＋端口为记录单位；以颜色和点形区分公开 P2P 与非公开／未确认可达，未知位置仍计入总数。地图提供分类数量、最后快照时间和节点信息，标明 IP 定位是估算，并说明探测失败不能证明永久关闭 P2P 服务。

访客通过可展开表单提交公网 IP 和可选端口（默认 8333）。确认、非 Purity、未完成本次验证及重复复验分别显示；重复记录不等于错误，候选记录未确认前不进入地图。超时提示验证结果尚未返回。加载失败提供重试，操作期间禁止重复提交。

后端保管 Seeder 凭证，用本地 GeoLite2-City 补充位置，实施来源限流与并发上限。60 秒缓存和刷新；完成提交后失效缓存并刷新。查询／添加的上游超时分别为 15／60 秒，添加不自动重试。界面沿用国际化、深色主题及移动端适配。本需求不包含服务部署或 Seeder 源代码修改。

## REQ-002：地图显示开关

前端配置 `PURITY_NODES_MAP_ENABLED` 为布尔值，默认开启。关闭时隐藏整张地图卡片和添加入口，也不发起该组件的节点请求或周期刷新。主网显示条件仍保留，不恢复旧卡片；该显示开关不改变后端接口可用性。Docker 前端可通过同名环境变量设置，修改后重新生成配置或重启容器并重新加载页面。

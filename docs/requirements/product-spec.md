# 产品规格

## REQ-001：Purity 节点地图

主网首页以整行地图替换 Ocean／Knots 两张卡片。仅统计 Seeder 哈希确认的 Purity 端点，IP＋端口为记录单位；以颜色和点形区分公开 P2P 与非公开／未确认可达，未知位置仍计入总数。地图提供分类数量、最后快照时间和节点信息，标明 IP 定位是估算，并说明探测失败不能证明永久关闭 P2P 服务。

访客通过可展开表单提交公网 IP 和可选端口（默认 8333）。确认、非 Purity、未完成本次验证及重复复验分别显示；重复记录不等于错误，候选记录未确认前不进入地图。超时提示验证结果尚未返回。加载失败提供重试，操作期间禁止重复提交。

后端保管 Seeder 凭证，用本地 GeoLite2-City 补充位置，实施来源限流与并发上限。60 秒缓存和刷新；完成提交后失效缓存并刷新。查询／添加的上游超时分别为 15／60 秒，添加不自动重试。界面沿用国际化、深色主题及移动端适配。本需求不包含服务部署或 Seeder 源代码修改。

## REQ-002：地图显示开关

前端配置 `PURITY_NODES_MAP_ENABLED` 为布尔值，默认开启。关闭时隐藏整张地图卡片和添加入口，也不发起该组件的节点请求或周期刷新。主网显示条件仍保留，不恢复旧卡片；该显示开关不改变后端接口可用性。Docker 前端可通过同名环境变量设置，修改后重新生成配置或重启容器并重新加载页面。

## REQ-003：后端冷启动同步

已有磁盘缓存的后端按交易 ID 计算增量，只抓取当前快照中的缺失交易，沿用过期交易删除和大规模清空保护。冷启动手续费元数据在每个 BitcoinApi 实例中只初始化一次；并发调用等待同一个 Promise，失败传递给所有等待者并清理在途状态，下一次可重试。命中缓存和 getmempoolentry 回退保持原有手续费计算。

初始同步记录 info 级数量和批次开始／完成；正常周期使用 debug；5 秒及以上的慢操作和失败汇总使用 warn。日志包含同步状态、Core／缓存／缺失／过期数量、批次成功／失败数、原始 RPC 慢请求、完整交易抓取耗时、超时分类及阶段耗时，不记录交易载荷、凭证或大量交易 ID。阈值是代码内诊断常量，不新增配置项，不取消或改变 RPC 结果。

watchdog 仍在 120 秒报告当前等待阶段；每次调用退出时始终清理，错误继续传播。并发仍为 8，失败交易沿用过滤语义，在后续快照周期仍缺失时重新抓取。保持 Electrum／Esplora、RBF、Redis 和磁盘缓存行为，不改共识、数据库、公开 API 或 RPC 认证／超时。传输层优化与生产部署单独执行。

## REQ-004：标记层级与后端节点类型

可访问节点始终位于非公开／未确认节点的上层，同坐标节点继续展开并可分别选中。实心圆与空心菱形分别表示上述可访问状态，分类筛选及原有统计不变。

前端取消 Archive / Prune 类型展示，包括类型颜色、图例、悬浮提示、选中详情和列表类型列。统一用绿色实心圆表示可访问，橙色空心菱形表示非公开／未确认，不读取 `node_type`。

后端类型识别及响应契约不变：依据 Seeder 库存中节点声明的服务能力，`NODE_NETWORK` 表示 Archive；仅有 `NODE_NETWORK_LIMITED` 表示 Prune；两个标志都有时为 Archive。缺失、无法精确读取或未声明上述能力时为未知。类型与可访问状态相互独立。本次调整仅修改前端及对应文档，不修改后端或 Seeder，不包含部署。

## REQ-005：永久 Reduced Data 共识状态

主网首页显示 “BIP-110 Reduced Data Rules”：高度 961637 起为 “Permanently Enforced”，更早高度为 “Not Yet Enforced”；显示已核实激活高度及 “Expiration: None”。依据 [Purity 共识规范](https://github.com/saltduck/bitcoinpurity/blob/b711f44afd1dee477674de997f81d544f1f432c6/doc/purity-consensus.md)，永久规则在硬分叉首块 961637 激活，永不过期，激活后无需版本位 4 强制投票。该高度独立于本项目 ASERT 配置；ASERT 行为不变。其他网络缺少固定 Purity 激活参数，省略此状态且不展示该卡片。

前后端使用精简 `PurityReducedDataStatus`，保留 `bip110deployment` 传输字段名。状态只根据主网及内存高度同步计算，无缓存、轮询、RPC、Electrum、SQL 或历史扫描；初始数据与订阅区块的实时客户端都接收状态。保留区块、mempool、费用和难度等现有内容。

删除临时部署的阈值、锁定、强制投票、到期倒计时和关联类型／样式。历史违规分类扫描的进度条、检测、计数与权重、徽章、版本位记录和持久化结果均保持原有行为。永久执行状态不用于重写历史分类，也不表示所有历史违规都是当时的共识无效交易。
